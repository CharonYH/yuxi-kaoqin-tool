# 羽茜考勤小助手

一个完全本地运行的考勤小助手，支持上传 `.xls` / `.xlsx` 标准考勤报表，自动识别“考勤记录”工作表并可视化展示。

## 使用方法

1. 双击打开 `index.html`。
2. 拖入或选择考勤报表。
3. 在月度矩阵中查看所有员工的打卡覆盖情况。
4. 点击任意色块查看对应员工整月详情。
5. 可按姓名、工号、打卡次数和日期范围筛选，并按姓名排序。
6. 可导出逐人逐日的原始打卡 CSV 明细。

## 数据说明

- 文件只在浏览器内解析，不会上传到网络。
- 仅接受恰好包含 `排班信息`、`考勤汇总`、`考勤记录`、`异常统计` 四个工作表的标准考勤表；缺少、多出或改名都会提示“请上传格式正确的考勤表”。
- 每个方格统一用数字表示当天打卡次数：`0` 为无记录、`1` 为一次、`2` 为两次，`3` 及以上显示实际次数；颜色与斜纹用于辅助区分。
- “无记录”按报表中的全部自然日统计，仅表示“考勤记录”单元格为空。
- 月份天数根据报表统计日期自动判断，支持 28、29、30、31 天；日期列与月份天数不一致时会拒绝解析。
- 星期由报表中的年份、月份和日期按公历计算，不依赖打开网页时的当前日期。
- “导出明细”可以把解析结果转换为逐人逐日的 CSV 文件。

## 功能范围

- 4 个工作表名称仅用于校验是否为标准考勤表。
- 业务数据只读取 `考勤记录`，不会读取 `排班信息`、`考勤汇总` 或 `异常统计` 的内容。
- 页面只展示员工、日期、星期、打卡次数和原始打卡时间，不判断迟到、早退、缺勤或排班状态。
- 支持整月、周一至周五、周末三种日期范围，以及报表顺序和姓名排序。

## 文件结构

- `index.html`：页面入口
- `styles.css`：页面样式
- `app.js`：Excel 解析和交互逻辑
- `parser.js`：报表解析核心
- `vendor/xlsx.full.min.js`：离线 Excel 解析库

## 部署到 GitHub Pages

项目是纯静态网页，可以直接部署到 GitHub Pages。仓库已包含自动部署工作流：

1. 在 GitHub 仓库中打开 `Settings` → `Pages`。
2. 将 `Build and deployment` 下的 `Source` 设为 `GitHub Actions`。
3. 把当前代码提交并推送到 `main` 分支。
4. 等待仓库 `Actions` 页中的 `Deploy to GitHub Pages` 工作流完成。

部署完成后，可通过以下地址直接访问：

```text
https://charonyh.github.io/yuxi-kaoqin-tool/
```

后续每次向 `main` 分支推送代码，网页都会自动更新。访客选择的 Excel 文件仍然只在其浏览器中解析，不会上传到 GitHub 或其他服务器。
