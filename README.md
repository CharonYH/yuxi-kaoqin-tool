# 羽茜考勤小助手

一个完全本地运行的考勤小助手，支持上传 `.xls` / `.xlsx` 标准考勤报表，自动识别“考勤记录”工作表并可视化展示。

## 使用方法

1. 双击打开 `index.html`。
2. 拖入或选择考勤报表。
3. 在月度矩阵中查看所有员工的打卡覆盖情况。
4. 点击任意色块查看对应员工整月详情。

## 数据说明

- 文件只在浏览器内解析，不会上传到网络。
- 仅接受恰好包含 `排班信息`、`考勤汇总`、`考勤记录`、`异常统计` 四个工作表的标准考勤表；缺少、多出或改名都会提示“请上传格式正确的考勤表”。
- 每个方格统一用数字表示当天打卡次数：`0` 为无记录、`1` 为一次、`2` 为两次，`3` 及以上显示实际次数；颜色与斜纹用于辅助区分。
- 页面不会根据固定上下班时间判断迟到或早退，避免不同班次造成误判。
- “无打卡”按报表中的全部自然日统计，仅表示单元格为空，不直接等同于缺勤。
- 月份天数根据报表统计日期自动判断，支持 28、29、30、31 天；日期列与月份天数不一致时会拒绝解析。
- 星期由报表中的年份、月份和日期按公历计算，不依赖打开网页时的当前日期。
- “导出明细”可以把解析结果转换为逐人逐日的 CSV 文件。

## 文件结构

- `index.html`：页面入口
- `styles.css`：页面样式
- `app.js`：Excel 解析和交互逻辑
- `vendor/xlsx.full.min.js`：离线 Excel 解析库
